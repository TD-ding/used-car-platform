# 二手车交易平台 - 管理后台文档

## 权限模型

三种角色，权限逐级递增：

| 角色 | 能力 |
|------|------|
| 普通用户 | 发布/管理自己的车辆、收藏、消息、个人中心 |
| 超级用户 | 普通用户 + 数据分析、置顶车辆、自动审核通过 |
| 管理员 | 超级用户 + 管理后台（用户管理、车辆审核、系统配置） |

## 管理后台页面

### 仪表盘 `/admin`
- 用户总数、已认证车辆数、待审核数、消息总数
- 最近7天注册量趋势
- 最近7天发布量趋势
- 品牌分布 TOP10

### 用户管理 `/admin/users`
- 用户列表（分页、搜索）
- 修改角色（admin/super/user）
- 修改状态（active/banned）
- 修改发布限额
- 删除用户（不能删自己）

### 车辆审核 `/admin/vehicles`
- 所有车辆列表（分页）
- 待审核车辆列表
- 审核通过/拒绝操作

### 系统配置 `/admin/config`
- 系统参数配置（预留扩展）

## 认证方式

- 前端路由守卫：`AdminRoute` 组件检查 `user.role === 'admin'`
- 后端中间件：`role('admin')` 检查 JWT token 中的角色字段
- 双重验证确保未授权用户无法访问管理接口
