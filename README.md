# 二手车交易平台

一个功能完整的二手车交易平台，支持管理员、超级用户和普通用户三种角色。

## 功能特性

- 用户注册/登录（三种角色权限）
- 车辆信息发布与管理
- 车辆搜索与筛选
- 图片上传
- 收藏与联系卖家
- 管理员后台管理
- 超级用户高级功能

## 技术栈

- 前端：React
- 后端：Node.js + Express
- 数据库：MySQL
- 容器化：Docker + docker-compose
