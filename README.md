# 二手商品交易平台

一个功能完整的二手商品交易平台，支持管理员、商家和普通用户三种角色。

## 技术栈

- **前端**: React + Vite
- **后端**: Python FastAPI
- **数据库**: PostgreSQL
- **部署**: Docker + Nginx

## 功能模块

- 用户系统：注册/登录、JWT认证、三种角色权限管理
- 商品管理：发布商品、编辑/下架、图片上传、分类筛选、搜索
- 交易流程：商品详情、下单/购买、订单状态跟踪
- 互动：商品留言/评论、站内消息
- 管理后台：用户管理、商品审核、数据统计
